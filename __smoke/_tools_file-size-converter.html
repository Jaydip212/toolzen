Why the same file has two sizes

Drive makers use decimal units: 1 GB = 1,000,000,000 bytes. Operating systems often report binary units: 1 GiB = 1,073,741,824 bytes. The same disk is therefore about 7% smaller when counted in GiB, which is why a “500 GB” drive shows as roughly 465 GiB. Nothing is missing — only the unit changed.

A KB is 1,000 bytes and a KiB is 1,024 — they are different units, not two spellings of the same one. This tool never silently swaps them.

File Size Converter — frequently asked questions

What is the difference between KB and KiB?

A kilobyte is 1,000 bytes and a kibibyte is 1,024. They are different units, not two spellings of the same one. Drive makers use decimal; most operating systems report binary.

Why does a 500 GB drive show as about 465 GiB?

Because 500,000,000,000 bytes is 500 GB in decimal but about 465 GiB in binary. Nothing is missing — only the unit changed.

Can it handle very large values?

Yes, up to terabytes in both families. The arithmetic is done in JavaScript numbers, which are exact for integers up to about 9 × 10¹⁵ bytes — far beyond any realistic file size.

Does it accept negative sizes?

No. A negative size is rejected with an explanation rather than converted into nonsense.
