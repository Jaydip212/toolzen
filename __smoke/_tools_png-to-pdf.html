PNG to PDF

Available

Combine PNG images into a single PDF document.

Choose a filePNG files only. Each becomes one page, in the order you add them.

Page

An image is scaled to fit inside the page and centred, so the aspect ratio is never changed. Transparent PNGs are flattened onto white, because PDF has no way to keep see-through areas over a page background.

How to use PNG to PDF

  1. 1Choose the PNG files you want in the document. Each becomes one page, in the order you add them.
  2. 2Pick the page size and the margin in millimetres. Zero prints to the edge.
  3. 3Press Build PDF and download.

PNG to PDF — frequently asked questions

What happens to the transparency in my PNGs?

It is flattened onto white. A PDF page has no way to show see-through areas over the paper background, so leaving transparency in would make those parts render as black. Flattening is what a printer would do anyway.

Is the result lossless like the PNG I uploaded?

No. The pages are embedded as JPEG at 92% quality to keep the file small, which is a re-encode rather than a copy of your exact bytes. For a pixel-perfect archive, use a ZIP file rather than a PDF.

Can I put several PNGs on one page?

Not here. Each image becomes its own page, which is what a document of scans or screenshots usually wants. Combining images onto a shared page is a layout job, not a conversion job.

Where do my files go?

Nowhere. The conversion runs in this browser tab, so your images are never uploaded and no copy is kept.
