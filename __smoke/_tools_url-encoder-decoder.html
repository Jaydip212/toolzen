URL Encoder & Decoder

Available

Percent-encode and decode URLs, query strings and form values.

What to do

encodeURIComponent — escapes / : ? # & = and everything else that is not unreserved. Use it for one value.

Paste something to encode or decode

Component mode escapes everything that is not unreserved, which is what you want for a single value. Full URL mode leaves the URL structure intact.

How to use URL Encoder & Decoder

  1. 1Choose Component for a single value, Full URL to keep the URL structure, or Query to read parameters.
  2. 2Switch between Encode and Decode.
  3. 3In Query mode, read the parameter table and the rebuilt query string.
  4. 4Copy the result you need.

URL Encoder & Decoder — frequently asked questions

Component or full URL?

Component escapes everything that is not unreserved, which is what you want for one value going into a query string. Full URL leaves the scheme, slashes, question mark and ampersand intact so the URL stays usable.

Why does a plus sign become a space?

In query strings, + is the historical encoding for a space. The query parser applies that rule; the Component mode does not, because + is a literal character outside a query string.

What happens with a malformed escape such as %ZZ?

You get a specific error naming the fragment, rather than a crash or a silently wrong result.

How are repeated keys shown?

As separate rows in the table, and as an array in the JSON view. Note that servers differ — some keep the first value, some the last.
