Image to PDF

Available

Combine images into a single PDF with control over page size and orientation.

Choose a fileEach image becomes one page, in the order you add them.

Page

An image is scaled to fit inside the page and centred, so the aspect ratio is never changed. Transparent PNGs are flattened onto white, because PDF has no way to keep see-through areas over a page background.

How to use Image to PDF

  1. 1Choose one or more images. Each becomes one page, in the order you add them.
  2. 2Pick the page size, A4 or US Letter in either orientation.
  3. 3Set the margin in millimetres. Zero prints to the edge.
  4. 4Press Build PDF and download the result.

Image to PDF — frequently asked questions

Will my image fill the whole page?

Only if the shape matches. The image is scaled to fit inside the page and centred, so the aspect ratio is never changed. A landscape photo on a portrait page ends up with bands above and below, which is the honest result.

What happens to a transparent PNG?

It is flattened onto white, because a PDF page has no way to show through. Without that step the transparent areas would come out black, which the tool avoids rather than describing as a feature.

Are the images embedded at full quality?

No, they are embedded as JPEG at 92 percent. That keeps the file small, and it means the PDF is not a pixel-identical copy of your originals. The tool states this rather than implying a lossless archive.

Can I reorder the pages afterwards?

Not from this tool. Add the images in the order you want them, because the pages follow that order. To change it, rebuild with the files added differently.
